# Cryptography Lab Activity

**Course:** Cryptography  
**Course Code:** CSL0509  
**Programme:** B.Tech – Artificial Intelligence and Machine Learning  
**Semester:** V

## About the Repository

This repository contains practical experiments performed as part of the Cryptography course. It includes hands-on activities related to encryption, decryption, hashing, digital signatures, digital certificates, key exchange, password security, and network traffic analysis.

Each experiment is maintained in a separate folder containing its README documentation and relevant screenshots.

## Tools and Software Used

The following tools and software are used across the practical experiments:

- **CrypTool 2** – Cryptographic algorithms and encryption demonstrations.
- **OpenSSL** – Encryption, hashing, key generation and digital certificates.
- **Wireshark** – Network traffic capture and analysis.
- **Command Line / Terminal** – Executing cryptographic commands and operations.
- **Git and GitHub** – Version control and practical documentation.

*The tools used vary depending on the requirements of each experiment.*
